### Unit 05 - reset --soft / --mixed / --hard, then recover with reflog
$ git reset --soft HEAD~1
$ git status --short
M  app.py
$ git reset HEAD~1
Unstaged changes after reset:
M	app.py
$ git status --short
 M app.py
$ git reset --hard HEAD~1
HEAD is now at 501e35f Revert "Canary: server1 runs v2.1.0 for 10% of traffic"
$ git status --short
$ git reflog -n 4
501e35f HEAD@{0}: reset: moving to HEAD~1
a9c5d17 HEAD@{1}: commit: Add secret data (mistake)
501e35f HEAD@{2}: reset: moving to HEAD~1
a9c5d17 HEAD@{3}: commit: Add secret data (mistake)
commit a9c5d17 is still in the reflog: git reset --hard a9c5d17 would bring it back
(here we leave it out: a secret must never be pushed)
